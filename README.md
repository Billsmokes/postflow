# PostFlow

Dashboard web layanan autopilot upload media sosial — **tanpa password, tanpa serahkeun akun**. Klien cukup klik "Hubungkan Akun" (OAuth/token resmi), sistem yang mengunggah, menjadwalkan, dan melaporkan.

Web app berbahasa Indonesia: cara kerja 5 langkah, hubungkan akun tanpa password, pilihan konten (dari kamu / dibuatkan), paket harga variasi, cara order, dan Tanya-Jawab.

## Cara pakai

Buka `index.html` di browser — atau aktifkan GitHub Pages di repo ini (Settings → Pages → Branch `main` → `/root`), lalu buka link Pages-nya.

## Catatan jujur

Ini **versi demo statis**: semua alur (hubungkan akun, caption AI, jadwal, laporan) disimulasikan di browser, **tanpa backend dan tanpa koneksi sungguhan ke API platform**. OAuth beneran, server 24/7, payment gateway, dan penyimpanan token terenkripsi adalah langkah berikutnya — lihat bagian "Blueprint" di dalam web-nya.
